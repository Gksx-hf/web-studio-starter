# 网页工坊 | Web Studio Starter

一个轻量、易扩展的网页项目起点，使用 Vite 和原生 JavaScript。

## 开始使用

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可预览。

## 常用命令

- `npm run dev`：启动本地开发服务器
- `npm run build`：生成生产版本到 `dist/`
- `npm run preview`：预览生产构建

.
